Get started with Silo.

Install Silo, build its development image, and open a shell in your project.

Requirements

Silo runs on Apple's container CLI. Its upstream supported environment is an Apple silicon Mac running macOS 26. Consult the official runtime requirements for current platform details.

Install from source

Install Rust 1.91 or newer with Cargo, then build and install the latest Silo source directly from GitHub:

cargo install --git https://github.com/serg-cs/silo --locked

Verify the installation:

silo --version

Your first session

Build the default development image:

silo image build

Move into a project and open a shell:

cd ~/code/my-project
silo run

Silo mounts the project as the container's working directory. When the shell exits, your project files remain on the host.
